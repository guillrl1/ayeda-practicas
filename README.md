# Algoritmos y Estructuras de Datos Avanzadas

Prácticas de la asignatura Algoritmos y Estructuras de Datos Avanzadas (AyEDA) · Universidad de La Laguna · Grado en Ingeniería Informática.

## Contenido

| Carpeta | Tema |
|---|---|
| `P01` | Números enteros de precisión arbitraria (`bigUnsigned`, `bigInteger`) |
| `P02` | Plantillas numéricas sobre enteros grandes (`bigRational`, `bigComplex`) |
| `P03` y `P04` | Calculadora (versiones `casa` y `clase`) |
| `P05` | Algoritmos de ordenación |
| `P06` | Árboles binarios, de búsqueda (ABB) y AVL |
| `preparacion-examen` | Implementaciones de algoritmos de ordenación y ejercicios de preparación |

Las carpetas `casa` contienen el trabajo realizado en casa y `clase` el realizado durante la sesión de laboratorio.

## Compilación

Cada práctica con `Makefile` se compila con:

```bash
make
```
